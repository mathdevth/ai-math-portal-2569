เจาะลึก “ลำดับและอนุกรม” ครบทุกหัวข้อย่อย

พอร์ทัลการเรียนรู้สำหรับครูคณิตศาสตร์ ม.5 พาสร้างเว็บแอปแบบ Interactive ด้วย Google Gemini ให้ครบทั้ง 6 หัวข้อย่อยของเรื่องลำดับและอนุกรม (ความหมายของลำดับ, ลำดับเลขคณิต, ลำดับเรขาคณิต, อนุกรมเลขคณิต, อนุกรมเรขาคณิต) พร้อมเชื่อมโยงสู่ ดอกเบี้ยและมูลค่าของเงินในชีวิตประจำวัน และปรับเปลี่ยนเนื้อหาเป็นบทเรียนอื่นได้ตามต้องการ!

หัวข้อย่อยในเว็บแอปที่ผู้เข้าอบรมจะได้สร้างจาก Prompt ของเรา (ครบตามโครงสร้าง สสวท. ม.5 พร้อมแสดงสมการ LaTeX คมชัด):
1 ความหมายลำดับ $a_n$
2 ลำดับเลขคณิต ($a_n$)
3 ลำดับเรขาคณิต ($a_n$)
4 อนุกรมเลขคณิต ($S_n$)
5 อนุกรมเรขาคณิต ($S_n$)
6 ดอกเบี้ย & มูลค่าเงิน

1. ลำดับเลขคณิต & เรขาคณิต

$$a_n = a_1 + (n-1)d \quad , \quad a_n = a_1 r^{n-1}$$

2. อนุกรมเลขคณิต ($S_n$)

$$S_n = \frac{n}{2}[2a_1 + (n-1)d]$$

3. อนุกรมเรขาคณิต ($S_n$)

$$S_n = \frac{a_1(1 - r^n)}{1 - r} \quad (r \neq 1)$$

4. ดอกเบี้ยทบต้น & ค่างวด

$$S = P\left(1 + \frac{r}{k}\right)^{kn}$$

หัวข้อย่อยที่ 1–3: ลำดับและการเห็นภาพ
พจน์แรก ($a_1$): 2
ผลต่างร่วม ($d$ สำหรับลำดับเลขคณิต): +3
อัตราส่วนร่วม ($r$ สำหรับลำดับเรขาคณิต): ×2
พจน์ที่ต้องการหา ($n$): พจน์ที่ 6 ($a_6$)

📐 กล่องแสดงวิธีทำแทนค่าสมการ LaTeX อัตโนมัติ:

แผนภาพเปรียบเทียบการเติบโตของแต่ละพจน์ ($a_1$ ถึง $a_n$)

สังเกตความต่างระหว่างการบวกเพิ่มคงที่ ($+d$) กับการคูณทบต้น ($\times r$)

ลำดับเลขคณิต ลำดับเรขาคณิต
เชื่อมโยงชีวิตประจำวัน: ลำดับเลขคณิตเปรียบเสมือน "การหยอดกระปุกเพิ่มวันละเท่าๆ กัน (ดอกเบี้ยคงต้น)" ส่วนลำดับเรขาคณิตคือรากฐานของ "การเติบโตของเงินฝากแบบดอกเบี้ยทบต้นและการแบ่งเซลล์"
หัวข้อย่อยที่ 4: อนุกรมเลขคณิต ($S_n$)

ช่วยให้เด็ก ม.5 เห็นภาพว่าทำไมสูตรผลบวกจึงเป็น $$S_n = \frac{n}{2}(a_1 + a_n)$$ โดยจำลองการจับคู่พจน์หน้าสุดกับพจน์ท้ายสุดของเกาส์!

พจน์แรก ($a_1$): 2
ผลต่างร่วม ($d$): 3
จำนวนพจน์ที่นำมาบวกกัน ($n$ คู่): 6 พจน์ (3 คู่)

แผนภาพการจับคู่พจน์หน้า-พจน์หลัง (Gauss Pairing Visualizer)

พจน์ที่มีสีเดียวกันเมื่อนำมาบวกกัน จะได้ผลลัพธ์เท่ากับ $(a_1 + a_n)$ เสมอ!

หัวข้อย่อยที่ 5: อนุกรมเรขาคณิต ($S_n$)

โจทย์คลาสสิกในหนังสือเรียน สสวท.: ปล่อยลูกบอลจากความสูงเริ่มต้น แล้วกระดอนขึ้นเป็นสัดส่วน $r$ ของความสูงเดิม

ความสูงเริ่มต้น ($a_1$ เมตร): 10 เมตร
สัดส่วนความสูงที่กระดอนขึ้น ($r$): 0.70 (70%)
จำนวนครั้งที่กระดอน ($n$ ครั้ง): 6 ครั้ง

จำลองวิถีความสูงของลูกบอลแต่ละครั้ง ($a_1, a_2, \dots, a_n$)

ความสูงลดลงเรื่อยๆ ตามลำดับเรขาคณิต $a_n = a_1 r^{n-1}$ และผลรวมคืออนุกรม $S_n$

หัวข้อย่อยที่ 6: ดอกเบี้ยทบต้นและค่างวดรายเดือน

เชื่อมโยงอนุกรมเรขาคณิตสู่การออมเงินทุกเดือน โดยแยกแสดง ขั้นที่ 1 (หาค่า $i$ และ $N$) เพื่อไม่ให้ผู้เรียนสับสน!

เงินออมสะสมรายเดือน ($R$ บาท/เดือน): 2,000 บาท
อัตราดอกเบี้ยต่อปี ($r\%$ ต่อปี ทบต้นทุกเดือน $k=12$): 6% ต่อปี
ระยะเวลาการออม ($n$ ปี): 5 ปี (60 งวด)

ผลลัพธ์การออมด้วยอนุกรมเรขาคณิต (เงินต้นสะสม vs ดอกเบี้ยทบต้น)

เงินต้นที่ฝากจริง ($R \times N$)

120,000 ฿

ดอกเบี้ยทบต้นที่งอกเงย

+19,540 ฿

เงินรวมอนาคต ($S_{\text{ปลายงวด}}$)

139,540 ฿

สัดส่วนเงินต้น: 86% สัดส่วนดอกเบี้ยทบต้น: 14%
💡 ทำไมต้องแยกขั้นที่ 1 ($i$ และ $N$)? เพราะนักเรียนมักเผลอแทนค่า $r = 6$ ลงในสูตรโดยตรง การบังคับให้ AI แสดงกล่องแปลงค่า $i = \frac{0.06}{12} = 0.005$ และ $N = 5 \times 12 = 60$ งวดก่อน จะช่วยให้เด็กเข้าใจที่มาอย่างแท้จริง

ภายในเว็บที่สร้างขึ้น จะมีปุ่ม "โหมดครูผู้สอน (แก้ไขโจทย์/เนื้อหา)" ให้ครูสามารถปรับเปลี่ยนโจทย์บนหน้าเว็บได้เองโดยไม่ต้องแก้โค้ด!

Master Mega Prompt #1: สร้างเว็บแอปครบทุกหัวข้อย่อย + เชื่อมโยงดอกเบี้ย + ปรับเนื้อหาได้ (Single-File HTML)

คุณคือผู้เชี่ยวชาญด้านการพัฒนาสื่อนวัตกรรมการศึกษาวิชา สำหรับนักเรียนชั้น ตามหลักสูตร สสวท. ช่วยสร้างเว็บแอปพลิเคชันแบบ Interactive เต็มรูปแบบ เรื่อง โดยเขียนโค้ดทั้งหมดรวมเป็น Single-File HTML ไฟล์เดียว (รวม HTML, Tailwind CSS CDN, Chart.js CDN, KaTeX CDN สำหรับแสดงสูตรคณิตศาสตร์ LaTeX และ JavaScript ไว้ในไฟล์ index.html)

ข้อกำหนดสำคัญเรื่องการแสดงสูตรคณิตศาสตร์ (LaTeX Math Rendering): ต้องติดตั้งไลบรารี KaTeX (หรือ MathJax) ผ่าน CDN ในแท็ก <head> และเขียนฟังก์ชันสั่งให้เรนเดอร์สมการคณิตศาสตร์ทุกจุดด้วยรูปแบบ LaTeX ที่สวยงามสมบูรณ์แบบ (เช่น เศษส่วน $\frac{a}{b}$, เลขยกกำลัง $r^{n-1}$, ตัวห้อย $a_n, S_n$) รวมถึงต้องเรียกฟังก์ชัน renderMathInElement ซ้ำทุกครั้งที่มีการเปลี่ยนค่าตัวแปรหรือแสดงวิธีทำแบบไดนามิก

ดีไซน์และโทนสี: ออกแบบในสไตล์ ใช้ฟอนต์ภาษาไทย 'Prompt' จาก Google Fonts รองรับการแสดงผลทั้งคอมพิวเตอร์และมือถือ

โครงสร้างเนื้อหาบังคับ (ต้องมีแถบเมนูสลับได้ครบทุกหัวข้อย่อยดังนี้): โดยมีรายละเอียดเชิงลึกในแต่ละแท็บดังนี้:

  1. แท็บที่ 1 ความหมายของลำดับ & รูปแบบภาพ (Visual Patterns): ให้ผู้เรียนทดลองเปลี่ยนจำนวนชั้นของรูปเรขาคณิต (เช่น การเรียงจุดสามเหลี่ยม/สี่เหลี่ยม) เพื่อค้นหาความสัมพันธ์ของพจน์ที่ $n$ ($a_n$) ของฟังก์ชันที่มีโดเมนเป็นเซตของจำนวนเต็มบวก
  2. แท็บที่ 2 ลำดับเลขคณิต ($a_n = a_1 + (n-1)d$): มี Slider ปรับค่า $a_1, d, n$ แสดงแผนภาพบล็อกความสูงเพิ่มขึ้นทีละ $d$ คงที่ พร้อมกล่องแสดงวิธีทำแทนค่าด้วยสมการ LaTeX ทีละบรรทัด และตัวอย่างชีวิตจริง (เช่น การออมเงินเพิ่มสัปดาห์ละเท่าๆ กัน หรือการจัดเก้าอี้ในหอประชุม)
  3. แท็บที่ 3 ลำดับเรขาคณิต ($a_n = a_1 r^{n-1}$): มี Slider ปรับค่า $a_1, r, n$ พร้อมกราฟ Chart.js เปรียบเทียบการเติบโตแบบลำดับเลขคณิต (เส้นตรง) กับลำดับเรขาคณิต (ทวีคูณ) และตัวอย่างชีวิตจริง (เช่น การแบ่งเซลล์ หรือการลดลงของมูลค่ารถยนต์ตามค่าเสื่อมราคา)
  4. แท็บที่ 4 อนุกรมเลขคณิต ($S_n$): สร้าง Interactive Visualization แสดงการจับคู่พจน์หน้า-พจน์หลังของเกาส์ (Gauss Pairing) เพื่อให้เห็นที่มาของสูตร $$S_n = \frac{n}{2}(a_1 + a_n) = \frac{n}{2}[2a_1 + (n-1)d]$$ พร้อมตารางเปรียบเทียบค่า $a_n$ กับผลบวกสะสม $S_n$
  5. แท็บที่ 5 อนุกรมเรขาคณิต ($S_n$): สร้างแบบจำลองเห็นภาพ (เช่น การปล่อยลูกบอลตกจากความสูงแล้วกระดอนขึ้นเป็นสัดส่วน $r$) พร้อมแสดงการแทนค่าสูตร $$S_n = \frac{a_1(1 - r^n)}{1 - r}$$ อย่างละเอียดด้วย LaTeX
  6. แท็บที่ 6 การประยุกต์เรื่องดอกเบี้ยทบต้นและมูลค่าของเงิน (TVM & Annuities): เชื่อมโยงลำดับและอนุกรมเรขาคณิตเข้ากับชีวิตจริง ได้แก่ ดอกเบี้ยทบต้น $$S = P\left(1 + \frac{r}{k}\right)^{kn}$$ และเงินรวมค่างวดผ่อนออมรายเดือน $$S_{\text{ปลายงวด}} = \frac{R\left((1 + i)^N - 1\right)}{i}$$ โดยต้องแสดง "ขั้นที่ 1: แปลงอัตราดอกเบี้ยต่องวด $i = \frac{r}{k}$ และจำนวนงวดทั้งหมด $N = n \times k$" ก่อนแทนค่าลงสมการเสมอเพื่อไม่ให้นักเรียนสับสน
  7. ฟีเจอร์พิเศษ (Editable Content & Cloud Save): มีปุ่ม "แก้ไขหัวข้อ/โจทย์สำหรับครู" ที่ให้ครูพิมพ์ปรับข้อความโจทย์บนหน้าเว็บได้ทันที และมีฟอร์มส่งคะแนนแบบทดสอบ 5 ข้อเข้าสู่ Google Sheets ผ่านตัวแปร GOOGLE_SCRIPT_URL

Mega Prompt #2: เน้นสื่อเห็นภาพเรื่องลำดับ พจน์ทั่วไป และการหาพจน์กลาง

ช่วยสร้างเว็บแอปพลิเคชันแบบ Single-File HTML (พร้อมติดตั้ง KaTeX CDN เพื่อแสดงสมการคณิตศาสตร์แบบ LaTeX) วิชา ระดับชั้น เรื่อง ในสไตล์ โดยเจาะลึกเฉพาะหัวข้อย่อยเรื่องลำดับ ได้แก่ ให้เห็นภาพชัดเจนที่สุดดังนี้:

  1. เครื่องมือค้นหาพจน์ทั่วไป (Pattern Finder): มีเกมให้ผู้เรียนดูรูปภาพการเรียงจุดหรือบล็อกในพจน์ที่ $a_1, a_2, a_3, a_4$ แล้วทดลองเลื่อนสไลเดอร์เพื่อทายจำนวนในพจน์ที่ $a_n$
  2. ห้องทดลองเปรียบเทียบลำดับเลขคณิต vs ลำดับเรขาคณิต: ปรับค่าพจน์แรก $a_1$, ผลต่างร่วม $d$ และอัตราส่วนร่วม $r$ (รองรับทั้งค่าบวก ค่าลบ และเศษส่วน) พร้อมแสดงสมการ LaTeX $$a_n = a_1 + (n-1)d \quad \text{และ} \quad a_n = a_1 r^{n-1}$$ คู่กับเส้นจำนวนและกราฟเปรียบเทียบ
  3. เครื่องมือแก้โจทย์หาพจน์ที่หายไป (Missing Terms Solver): ให้ผู้เรียนป้อนค่า 2 พจน์ใดๆ (เช่น รู้ค่า $a_3$ และ $a_7$) แล้วให้โปรแกรมแสดงวิธีทำระบบสมการหาค่า $d$ หรือ $r$ และพจน์แรก $a_1$ ออกมาทีละขั้นตอนด้วยสมการ LaTeX ตามหลักสูตร สสวท.

Mega Prompt #3: เชื่อมโยงผลบวกอนุกรม $S_n$ สู่ดอกเบี้ยทบต้นและค่างวดในชีวิตประจำวัน

ช่วยสร้างเว็บแอปพลิเคชันแบบ Single-File HTML (พร้อมติดตั้ง KaTeX CDN แสดงสมการ LaTeX ทุกจุด) สำหรับวิชา ชั้น เรื่อง ในสไตล์ โดยเน้นการเชื่อมโยงจากอนุกรมเลขคณิตและอนุกรมเรขาคณิต ไปสู่การคำนวณดอกเบี้ยและมูลค่าของเงินตามหนังสือเรียน สสวท. ดังนี้:

  1. Interactive Series Visualizer: แสดงแผนภาพการบวกทบยอดทีละพจน์ ($S_n = a_1 + a_2 + a_3 + \dots + a_n$) เปรียบเทียบกับค่าของพจน์ที่ $n$ ($a_n$) เพื่อแก้ปัญหานักเรียนสับสนระหว่างสูตรหาพจน์กับสูตรหาผลบวก
  2. การเชื่อมโยงสู่มูลค่าของเงินตามเวลา (TVM Bridge): แสดงแผนภาพเส้นเวลา (Cash Flow Timeline) อธิบายว่าการฝากเงินทุกงวด งวดละ $R$ บาท เมื่อคิดดอกเบี้ยทบต้นแต่ละก้อน จะกลายเป็นพจน์ของอนุกรมเรขาคณิต $$R(1+i) + R(1+i)^2 + \dots + R(1+i)^N$$ ที่นำมารวมกันได้อย่างไร
  3. เครื่องคำนวณดอกเบี้ยทบต้นและค่างวด (ต้นงวด/ปลายงวด): แสดงกล่องวิธีทำด้วย LaTeX 2 ขั้นตอนชัดเจน คือ ขั้นที่ 1 แปลงอัตราดอกเบี้ยต่องวด $i = \frac{r}{100 \times k}$ และจำนวนงวด $N = n \times k$ และ ขั้นที่ 2 แทนค่าลงในสูตรอนุกรมเรขาคณิต พร้อมแยกแสดงเงินต้นสะสมทั้งหมด $(\text{ค่างวด} \times \text{จำนวนงวด})$ และดอกเบี้ยสุทธิ

โค้ดหลังบ้าน Google Apps Script (Code.gs) 
function doPost(e) {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName("Scores") || ss.insertSheet("Scores");
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["Timestamp", "StudentID", "FullName", "ClassRoom", "Topic", "Score", "Details"]);
  }
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    new Date(),
    data.studentId || "-",
    data.fullName || "-",
    data.classRoom || "ม.5",
    data.topic || "ลำดับและอนุกรม",
    data.score || 0,
    data.details || ""
  ]);
  return ContentService.createTextOutput(JSON.stringify({ status: "success" }))
    .setMimeType(ContentService.MimeType.JSON);
}

  • ตรวจคำตอบทุกข้อ: AI คำนวณผิดหรือใช้สูตรผิดได้ ลองแทนค่าด้วยมือ 2–3 ชุดก่อนนำไปสอนจริง

  • ข้อมูลส่วนบุคคล: ไม่ใส่เลขบัตรประชาชนหรือข้อมูลอ่อนไหวของนักเรียน และตั้งค่า Google Sheets ไม่ให้คนนอกเปิดดูได้
  • อย่าเผยแพร่ลิงก์แก้ไขชีต: ลิงก์ Web App URL ใส่ในโค้ดได้ แต่ลิงก์ไฟล์ Google Sheets ห้ามใส่ลงหน้าเว็บสาธารณะ
